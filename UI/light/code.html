Have Questions?

Frequently Asked Questions

Everything you need to know about adopting OmniOPS.

Can OmniOPS be deployed on-premise or air-gapped?

expand_more
Yes. OmniOPS Enterprise includes self-hosted Helm charts that can be installed on private Kubernetes clusters, AWS GovCloud, or isolated bare-metal servers with no external outbound connectivity requirements.

Is the OmniOPS CLI free for developers?

expand_more
Yes! The CLI client is 100% free and open-source. Any individual developer can link their local Docker daemon, minikube or GitHub repos directly without a paid subscription.

Does OmniOPS replace GitHub Actions or ArgoCD?

expand_more
No, it acts as an intelligent orchestration layer on top of them. You can continue running your existing GitHub Actions, GitLab CI, or ArgoCD workflows; OmniOPS unifies their triggers, statuses, logs, and canary controls in one interface.

How does the Diagnostic AI Assistant ensure security?

expand_more
The AI engine analyzes abstracted telemetry, anonymized stack traces, and cluster topology without sending customer PII or sensitive secret payloads to third parties. Dedicated private model VPC options are available.
